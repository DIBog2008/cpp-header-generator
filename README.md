# C++ Header Generator

**Автор:** Богачков Дмитрий Иванович, 3111

## Описание
Плагин для VS Code, который анализирует открытый файл C++ и создаёт рядом с ним новый заголовочный файл `<имя_файла>_functions.h`, содержащий **только объявления (прототипы)** всех функций, находящихся вне пространств имён (`namespace`).

## Возможности
- Анализ текста текущего открытого файла `.cpp`.
- Поиск объявлений функций с помощью регулярных выражений.
- Игнорирование функции `main`.
- Удаление дубликатов: если функция с такой же сигнатурой уже была найдена, повторно она не добавляется.
- Игнорирование функций, находящихся внутри `namespace`.
- Игнорирование комментариев (`//` и `/* ... */`) и ключевых слов (`if`, `while`, `for`, `switch`, `return`, `sizeof`).
- Автоматическое добавление `#pragma once` в начало созданного файла.
- Создание нового файла `*_functions.h` рядом с исходным файлом, содержащего список прототипов функций.
- Автоматическое открытие созданного файла в редакторе.

## Использование
1. Откройте любой файл `.cpp` в VS Code.
2. Нажмите `Ctrl+Shift+P` (или `Cmd+Shift+P` на Mac), чтобы открыть палитру команд.
3. Введите `Generate C++ Function Header` и выберите команду.
4. Рядом с вашим `.cpp` файлом появится новый файл с суффиксом `_functions.h`, содержащий только объявления функций.
5. Созданный файл автоматически откроется в редакторе.

## Технологии 

* `TypeScript` — язык программирования для написания логики расширения.

* `Node.js` — среда выполнения для сборки и работы инструментов разработки.

* `VS Code Extension API` — официальный интерфейс для интеграции с редактором (команды, работа с документами, файловая система).

* `esbuild` — быстрый сборщик для компиляции TypeScript в JavaScript.

* `ESLint` — статический анализатор кода для поддержания качества кода.

* `vsce (Visual Studio Code Extension Manager)` — официальный CLI-инструмент для упаковки расширения в .vsix файл.

## Установка

1. Скачайте файл `cpp-header-generator-0.0.1.vsix` из раздела `Releases` на странице репозитория `GitHub`.
2. Откройте `VS Code`.
3. Нажмите `Ctrl+Shift+X` (или `Cmd+Shift+X` на Mac), чтобы открыть панель расширений.
4. Нажмите на три точки ... в правом верхнем углу панели и выберите `Install from VSIX....`
5. Найдите скачанный файл `.vsix` и выберите его.
6. Если `VS Code` попросит перезагрузиться, нажмите `Reload Required`.
7. Плагин установлен, теперь команда `Generate C++ Function Header` доступна в палитре команд.

### Пример использования 
Если вы открыли файл `main.cpp`:
```cpp
namespace MyNamespace {
    void hiddenFunc() {}
}

int add(int a, int b);

int add(int a, int b) {
    return a + b;
}

void printHello() {
    std::cout << "Hello";
}
int main() {
    return 0;
}
```
После работы плагина создаётся файл `main_functions.h`:
```c++
#pragma once

int add(int a, int b);

void printHello();
```
